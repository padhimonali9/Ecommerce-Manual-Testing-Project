# E-commerce Website Manual Testing – SauceDemo

## Project Overview

This project demonstrates manual functional testing of the [SauceDemo demo e-commerce website](https://www.saucedemo.com/). The objective was to practise designing and executing test cases, validating expected versus actual results, and documenting test outcomes using Microsoft Excel.

The project covers key e-commerce workflows, including product browsing, shopping cart operations, product sorting, checkout form validation, and the checkout process.

> **Project Type:** Personal Practice Project  
> **Testing Approach:** Manual Functional Testing  
> **Application:** SauceDemo  
> **Documentation Tool:** Microsoft Excel

---

## Tools Used

- **Microsoft Excel** – Test case documentation, execution tracking, and test result reporting
- **SauceDemo** – Demo e-commerce application used for functional testing

## Testing Scope

The following functional areas were covered during test execution:

| Test Area | Testing Coverage |
|---|---|
| Product Browsing | Product listing and product details |
| Shopping Cart | Adding and removing products |
| Cart Validation | Cart item count and price validation |
| Product Sorting | Validation of product sorting functionality |
| Checkout Form | Checkout information and form validation |
| Checkout Workflow | Validation of the checkout process |

## Project Deliverables

### 1. Test Case Execution Sheet
Documented test scenarios, test steps, expected results, actual results, and execution status in Microsoft Excel.

### 2. Defect Log
Prepared a defect-tracking format to record and organize identified issues. No defects were identified during this test execution.

### 3. Test Execution Summary
Summarized the number of executed test cases, pass/fail results, blocked cases, and overall pass percentage.
